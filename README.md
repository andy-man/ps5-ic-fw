# About

PS5 southbridge/usb_pdc firmware collection

**Structure:** [emc/usb_pdc] / [type] / [fw_range]_[md5].2bls

For `usb_pdc`, files are grouped by container: `usb_pdc/[type]/[c]/[fw_range]_[md5].2bls`

**Example:** `emc/24/1000-1001_421ea7fec14cf827f6380326ab9fe42b.2bls`

**USB PDC example:** `usb_pdc/12/C0050001/0112-0451_1c6b88bff5d3cb1fe5fcc15be5c7f7e9.2bls`
